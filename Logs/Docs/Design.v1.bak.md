# 模拟手机聊天系统 - 功能设计文档

## 1. 项目概述

- **项目定位**：复刻《崩坏：星穹铁道》《无限大》等游戏内手机聊天系统，包含玩家侧交互与策划侧数据编辑工具。
- **核心目标**：实现沉浸式剧情对话体验，同时提供策划无代码配置内容的可视化工作流。
- **引擎**：Unity 2022.3 LTS
- **UI 系统**：UGUI + TextMeshPro (TMP)

---

## 2. 整体 UI 布局

界面分为左右两个面板：

- **左侧面板（联系人列表，约占 30% 宽度）**：深黑色背景，展示“新消息通知”列表。
- **右侧面板（聊天窗口，约占 70% 宽度）**：浅灰白色背景，展示具体聊天记录和回复选项。

---

## 3. 玩家侧功能拆解

### 3.1 左侧面板：联系人列表（Contact List）

- **标题栏**：顶部显示“新消息通知”文本。
- **联系人列表项（ScrollRect + 对象池优化）**：
  - **头像**：圆形头像，支持网络/本地加载。
  - **名字**：联系人备注名，如：知更鸟、吉尔伽美什。
  - **消息预览**：最近一条消息的摘要，需要自适应截断，例如：“原本是希望你能够享受…”、“[表情]”。
  - **状态角标**：右侧小箭头（`>`），表示可点击进入。
  - **未读红点提示**：
    - 有未读消息时，头像右上角显示红点。
    - 进入聊天后，红点自动消失。
- **选中状态**：当前正在聊天的联系人，列表项有不同背景色（浅灰白色）。

### 3.2 右侧面板：聊天窗口（Chat Window）

#### 3.2.1 顶部栏（Header）

- **联系人名字**：当前聊天的 NPC 名字，如：知更鸟。
- **签名 / 状态**：名字下方显示 NPC 的个性签名，如：“让我们把翅膀借给彼此”。
- **关闭按钮**：右上角 `X` 按钮，点击后关闭整个手机界面（该Demo中为退出游戏运行状态）。

#### 3.2.2 聊天区域（Chat Content）

- **消息列表**：使用 `ScrollRect`，包含各类消息气泡。
- **双方方气泡**：
  - 包含圆形头像 + NPC 名字 + 气泡内容。
  - 内容支持：纯文本、Emoji（图文混排）、表情包（图片）、图片。
- **消息自适应与时间线**：
  - 气泡随内容长短自动拉伸（`ContentSizeFitter` + `VerticalLayoutGroup`）。
  - 超过一定时间间隔（如 5 分钟），插入居中的时间分割线。

#### 3.2.3 底部栏：回复选项区（Reply Options）

- 当玩家需要回复时弹出底部包含回复选项的面板。
- **预设选项按钮**：底部显示多个白色圆角按钮，例如：“想要下次演出的票”、“我反复看演出录播”。
- **点击反馈**：点击按钮后，该内容作为玩家消息发送，随后面板消失，弹出 NPC 的后续对话。

---

## 4. 策划侧功能（编辑器工具）

为了让上述 UI 能动态展示，策划需要以下配置工具：

### 4.1 对话节点编辑器（Dialogue Editor）

- **配置项**：NPC 名字、头像、个性签名、发送延迟。
- **消息节点**：可添加文本、表情包、图片。
- **选项节点**：配置底部玩家回复选项，并连接对应的后续节点。
- **状态控制**：控制联系人列表的未读红点状态、消息预览内容。

### 4.2 数据驱动机制

- 聊天记录使用本地 JSON 存档。
- 对话配置使用 `ScriptableObject` 资产化存储，支持修改后无需改代码即可在游戏中预览。

---

## 5. MVP 开发优先级（1 周冲刺版）

### 5.1 必须完成的核心体验

1. **双面板 UI 搭建**：左侧联系人列表 + 右侧聊天窗口。
2. **联系人列表**：显示头像、名字、消息预览、未读红点。
3. **聊天窗口**：NPC 头像、名字、左右气泡自适应、表情包/图片展示。
4. **底部选项按钮**：点击按钮发送消息并触发 NPC 回复。
5. **性能优化**：列表使用对象池，防卡顿。
6. **简单存档**：聊天记录持久化。

### 5.2 暂时搁置的进阶功能

- 玩家手动输入文本框（完全依赖选项按钮推进剧情）。
- 群聊系统、视频消息、复杂的拖拽节点图编辑器（初期可用脚本 / CSV 直接配表）。
