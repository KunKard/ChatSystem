## ⚠️ 先读这段：为什么加完布局组后子物体会重叠

这是最容易卡住的地方，理解了后面就顺了。

`VerticalLayoutGroup` 勾了 `Child Control Height` 之后，它会去问每个子物体：**"你想要多高？"**
问的方式是 `LayoutUtility.GetPreferredHeight(child)`。

**一个"裸"的 `RectTransform`（没挂 `LayoutElement`、也没挂 `ContentSizeFitter`）回答是 0。**

于是布局组算出每条消息高度都是 0，把它们全部堆在同一个 Y 上 —— 看起来就是"重叠"。

**所以：只要父节点勾了 `Child Control Width/Height`，每个子物体就必须能报出自己的尺寸**，方式二选一：

- 挂 `LayoutElement` 填 `Preferred Height`（固定高度的东西，比如头像、列表项）
- 挂 `ContentSizeFitter`（内容驱动的，比如气泡）

两类必须**配对出现**，不能只改一边。

## ⚠️ 再读这段：气泡怎么做到一个靠左、一个靠右

**单个 `VerticalLayoutGroup` 做不到左右分列。** 它的 `Child Alignment` 是**整组统一**的，
没有"第 1 个靠左、第 2 个靠右"这种设置。所以左右分列要拆成两层：

| 层 | 组件 | 设置 | 作用 |
|---|---|---|---|
| ① 列表层 | `Content` 的 `VerticalLayoutGroup` | `Child Force Expand Width` = **✅ 勾上** | 让**每个气泡根节点都占满整行宽** |
| ② 气泡层 | 气泡根节点的 `HorizontalLayoutGroup` | `Child Alignment` = `Middle Left`（NPC）/ `Middle Right`（玩家） | 决定气泡内容贴左还是贴右 |

气泡根节点是满宽的，但它**没有背景图**，所以看不出来；背景图在 `TextBubble` 上，会跟着对齐走。

> 📌 **这条是 v1 写错的地方。** v1 让 `Content` 的 `Child Force Expand Width` **不要勾**，
> 理由是"勾了气泡会被拉满整行"—— 但拉满整行**恰恰是左右分列的前提**。
> 不勾的话，`Content` 的 `Child Alignment` 会统一决定所有气泡的位置，结果就是全挤在左边。

## 步骤 1：修 `Viewport` 零尺寸（🔴 最优先）

1. Hierarchy 选中 `Canvas/RightBackGround/Scroll View/Viewport`
2. Inspector 顶部 **RectTransform** 左上角的 **Anchor Presets** 方块，点开
3. 按住 **Shift + Alt**，点右下角的 **stretch / stretch** 预设
4. 只改一个值：**`Right = 20`**（给滚动条让位），`Left` / `Top` / `Bottom` 保持 `0`
5. 对 `Canvas/LeftBackGround/Scroll View/Viewport` **重复**

改完应为：

| 字段 | 值 |
|---|---|
| Anchor Min / Max | `(0, 0)` / `(1, 1)` |
| Left / Right | `0` / `20` |
| Top / Bottom | `0` / `0` |

**`Content` 不用动** —— 它的 `aMin=(0,1) / aMax=(1,1) / pivot=(0,1)` 本来就是竖向列表的标准配置，
只是父级 `Viewport` 宽为 0 才跟着变 0 宽。

## 步骤 5：重构两个气泡预制体

> 工程里的 `Content` 节点相当于 `Design.md` §5.2.3 里的 `BubbleColumn`。

### 🔴 三个必须做对的点

1. **`LayoutElement` 一个都不能少** —— 缺了就是重叠或变形（见前文）
2. **所有 `Child Force Expand` 必须取消勾选** —— 新建布局组时 Unity 默认是**勾上的**，
   不取消会导致：头像被拉成长方形、文字框被拉得比文字宽得多
3. **`Text` 的 TMP 必须勾 `Enable Word Wrapping`**

## 附：为什么不能"给 `ContentSizeFitter` 勾上 Horizontal"

源码实证（`TMP_Text.cs`）：

```csharp
protected float GetPreferredWidth()          // 宽度
{
    Vector2 margin = k_LargePositiveVector2;                            // (INT_MAX, INT_MAX)
    float preferredWidth = CalculatePreferredValues(ref fontSize, margin, false, false).x;
}                                                               //        ↑ isWordWrappingEnabled = false

protected float GetPreferredHeight()         // 高度
{
    Vector2 margin = new Vector2(m_marginWidth != 0 ? m_marginWidth : k_LargePositiveFloat, ...);
    preferredHeight = CalculatePreferredValues(ref fontSize, margin, m_enableAutoSizing, m_enableWordWrapping).y;
}                                                               //                          ↑ 换行是开着的
```

**宽度方向**：以"无限可用宽度 + 关闭换行"计算 → 返回**不换行的整行宽度**。
若让 `ContentSizeFitter` 用这个值，长文本气泡会无限变宽且永不换行。

**高度方向**：用**真实 rect 宽度**计算，且**换行是开着的** → 值是正确的。

所以：**横向 `Unconstrained`，纵向 `PreferredSize`；宽度上限交给 `ClampPreferredWidth`。**
`ClampPreferredWidth` 用 `layoutPriority = 2` 覆盖内置组件（`LayoutGroup` = 0、`TMP_Text` = 0、`LayoutElement` = 1），
高度方向返回 `-1` 让位给 `VerticalLayoutGroup`。详见该文件头部注释。
