## 步骤 1：修 `Viewport` 零尺寸（🔴 最优先）

两个都改，操作完全一样。

1. Hierarchy 选中 `Canvas/RightBackGround/Scroll View/Viewport`
2. Inspector 最上方 **RectTransform** 左上角有个 **Anchor Presets** 方块（一格一格那个），点开
3. 按住 **Shift + Alt**，点右下角那个 **stretch / stretch** 预设
   - Shift = 同时设置 pivot，Alt = 同时把 offsets 归零
4. 回到 RectTransform，只改一个值：**`Right = 20`**（给右边的滚动条让位）
   - `Left` / `Top` / `Bottom` 保持 `0`
5. 对 `Canvas/LeftBackGround/Scroll View/Viewport` **重复 1~4**

改完 `Viewport` 的 RectTransform 应该是：

| 字段 | 值 |
|---|---|
| Anchor Min | `(0, 0)` |
| Anchor Max | `(1, 1)` |
| Left / Right | `0` / `20` |
| Top / Bottom | `0` / `0` |
| Pivot | `(0.5, 0.5)` |

**`Content` 不用动。** 它的 `aMin=(0,1) / aMax=(1,1) / pivot=(0,1)` 本来就是做竖向列表的标准配置，只是父级 `Viewport` 宽度是 0，才跟着变成了 0 宽。第 1 步做完它自动就有宽度了。

## 步骤 3：给两个 `Content` 加布局组

### 3.1 右侧 `Content`（消息列表）

选中 `Canvas/RightBackGround/Scroll View/Viewport/Content`，**Add Component**：

**① `Vertical Layout Group`**

| 字段 | 值 | 说明 |
|---|---|---|
| Padding → Left / Right | `24` / `24` | 气泡不贴边 |
| Padding → Top / Bottom | `16` / `16` | |
| Spacing | `16` | 消息之间的间距 |
| Child Alignment | `Upper Left` | |
| Child Controls Size → Width | ✅ | 让气泡自己决定宽度 |
| Child Controls Size → Height | ✅ | 让气泡自己决定高度 |
| Child Force Expand → Width | ⬜ **不勾** | 勾了气泡会被拉满整行 |
| Child Force Expand → Height | ⬜ 不勾 | |

**② `Content Size Fitter`**

| 字段 | 值 |
|---|---|
| Horizontal Fit | **Unconstrained** |
| Vertical Fit | **Preferred Size** |

> ⚠️ `Horizontal Fit` 必须是 `Unconstrained`。宽度由锚点拉伸（`aMin.x=0 / aMax.x=1`）决定，
> 交给 `ContentSizeFitter` 管会和 `ScrollRect` 打架。

## 步骤 5：重构两个气泡预制体（🔴 工作量最大的一步）

> 目标结构来自 `Design.md` §5.2.3。工程里实际的 `Content` 节点相当于文档里的 `BubbleColumn`，
> 对应关系已在下图标出。

**改之前请先明确一件事**：现在两个气泡预制体里**每个节点都是 `aMin == aMax` 的点锚点 + 手工调的 `pos`**，
这是"在 1920×1080 下调好看"的做法。要让文本长度变化时气泡自动适应，内部层级必须重组，
不是加一两个组件能解决的。

### 5.1 `ChatBubble.prefab`（NPC，左对齐）

目标结构：

```text
ChatBubble  (root)
├─ [新增] Horizontal Layout Group   childAlignment = Middle Left
│                                   childControlWidth/Height = ✅
│                                   childForceExpandWidth = ⬜
├─ [新增] Content Size Fitter       Horizontal = Unconstrained
│                                   Vertical   = Preferred Size
│
├─ Avatar          [新增 Layout Element] Min/Max Width = 80, Min/Max Height = 80, Flexible = 0
│
└─ Content         ← 把 Name 拖进来，成为它的第一个子节点
     ├─ [新增] Vertical Layout Group   childAlignment = Upper Left
     │                                 childControlWidth = ✅, childForceExpandWidth = ⬜
     ├─ Name       (TMP，保持现有字号/颜色)
     └─ TextBubble
          ├─ [新增] Vertical Layout Group  +  Content Size Fitter (Vertical = PreferredSize)
          ├─ [新增] ClampPreferredWidth    maxWidth = 760     ← 这个组件由 T6 提供
          └─ Text    (TMP，唯一的子节点)
```

具体操作：

1. **`Name` 换父节点**：Hierarchy 里把 `Name` 拖到 `Content` 上，成为 `Content` 的第一个子节点
2. **`BackGround` 的图挪到 `TextBubble`**：
   - 选中 `Content/TextBubble` → Add Component → `Image`，把 `BackGround` 上的 `Sprite` 与 `Color` 照抄过来
   - 删除 `BackGround` 节点
   - 原因：`TextBubble` 自己能当底图，就不需要多一个兄弟节点去挤布局
3. **`Text` 拖到 `TextBubble` 下**（如果它已经在就别动），确保 `TextBubble` 的**唯一子节点**是 `Text`
4. **`TextBubble` 加组件**：
   - `Vertical Layout Group`：Padding 给气泡内边距（建议 左/右 `20`，上/下 `14`），
     Child Controls Size 全 ✅，Child Force Expand 全 ⬜
   - `Content Size Fitter`：`Vertical = PreferredSize`，`Horizontal = Unconstrained`
   - `ClampPreferredWidth`：`maxWidth = 760`（T6 会给出这个组件）
5. **`Text` 上的 TMP 必须勾上 `Enable Word Wrapping`** ⚠️ 漏了这个前面全白做
6. **`Content` 加 `Vertical Layout Group`**：`Child Alignment = Upper Left`，
   Child Controls Size 全 ✅，Child Force Expand 全 ⬜
7. **根节点 `ChatBubble` 加组件**：
   - `Horizontal Layout Group`：`Child Alignment = Middle Left`，
     Child Controls Size 全 ✅，`Child Force Expand Width/Height` 全 ⬜
   - `Content Size Fitter`：`Vertical = PreferredSize`，`Horizontal = Unconstrained`
8. **`Avatar` 加 `Layout Element`**：`Min/Max Width = 80`，`Min/Max Height = 80`，`Flexible Width = 0`
9. 根节点的 `RectTransform` 改成：**Anchor Min/Max = `(0, 1)`，Pivot = `(0.5, 1)`**

## 附：这一步为什么不能跳过

`Design.md` §5.2.3 把气泡宽度称作"本项目最大的技术坑"。坑的具体形状是：

> 若气泡的 `ContentSizeFitter` 勾了 `Horizontal = PreferredSize`，
> TMP 报告的 `preferredWidth` 是**文本不换行的整行宽度**，而父级又不提供宽度约束，
> 结果是长文本气泡**无限变宽撑破面板，且永远不换行**。

所以整套方案的关键在于**宽度不由 `ContentSizeFitter` 决定，而是被 `ClampPreferredWidth` 钳住上限**，
`ContentSizeFitter` 只管高度。上面步骤 5 里那两条 `Horizontal = Unconstrained` 就是在落实这一点，
**不是随手选的默认值**。
